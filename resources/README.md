# Resources

Small reference inputs, small enough to version alongside the code.

| File | What it is |
|---|---|
| `specs_zambia.xlsx` | The OnSSET specs workbook: scenario parameters before calibration |
| `specs_zambia_calibrated_2026-06-20.xlsx` | After base-year calibration |
| `specs_zambia_calibrated_distgate_2026-06-20.xlsx` | Calibrated with the 2 km transformer distance gate — **this is the variant used for the published results** |
| `specs_zambia_2050_TEMPLATE.xlsx` | Specs template for the 2050 endpoint run |

Parameter sourcing is in `docs/02_variables.md`; the run-time dials are in `config/config.yaml`.
